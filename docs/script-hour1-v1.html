画面黑掉。手机掉落的声音。风声。城市底层的车流声由远及近。

画面从黑屏中缓缓亮起——不是光，是一种灰色的、不完整的亮。 像是透过裂缝看世界。玩家看到一个模糊的、失焦的画面：高楼天台边缘，一只脚迈出去。

然后坠落感。画面急速下坠——风声灌满耳朵——

突然停止。不是落地。是被什么接住了。 画面变成纯白。安静。只有心跳声。

……
你不该在这里结束。
但你也回不去了。

白屏渐暗，不是黑，是一种灰蓝色——介于存在与不存在之间。

// 悬念钩设计

核心悬念："上一世坑死你的那个人就在这30人里，而且你可能刚刚选了他。"

这个钩子利用了三个层面的张力：
1. 信息不对称——玩家知道"有人在"，但不知道"是谁"
2. 选择后果——玩家刚做了一个选择，选择本身可能就是陷阱
3. 时间压力——赛季在推进，每一步都在消耗应援值和直觉灵敏度

驱动力：玩家会在第2小时迫不及待地想要更多信号——更多日记、更多监控、更多观察机会。 而这正好是周更内容的节奏。

// 与周更内容的衔接

第1小时结束后的等待期，由周更内容填补：
舞台表演 → 提供舞台热忱轴的更多信号
偶像日记+周记 → 提供私下状态的文字信号
练歌房/练舞房监控 → 提供无人关注时的行为信号

三轴信号源与三轴真心值精确对应，确保玩家在第1小时建立的判断框架可以立即应用到周更内容中。
