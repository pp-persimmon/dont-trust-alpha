## 1. 设计概述

### 1.1 核心设计意图

玩家在上一世被一个偶像欺骗，倾家荡产。重生后她带着一个执念进入新赛季：

> **找到那个上一世欺骗你、令你一无所有的人。**

这是游戏的**唯一主线**。整个赛季的一切——观察、推理、脉冲、对质——都服务于这一个目标。

但在追猎孽缘的过程中，玩家会自然地遇到另一个人——一个三轴全真的本命候选。这个人是否值得信任？是否值得押上全部身家？这就是**条件线**：找到本轮真正的C位。

**条件线之所以是"条件线"：只有复仇成功后，找到C位才有意义。** 如果玩家连上一世的仇人都没能识破，那即使投对了C位，也不过是用新的盲目替代了旧的盲目——你没有真正从过去中醒来，你只是碰巧赌对了一次。下一世你还会被欺骗，因为你的判断力从未被真正校准过。

**一句话总结**：复仇是骨头，C位是肉。没有骨头的肉是一摊烂泥。

### 1.2 主线与条件线的关系

| 维度 | 主线（复仇线） | 条件线（C位线） |
|------|---------------|----------------|
| 代号 | Quest A | Quest B |
| 目标 | 找到上一世欺骗你的偶像 | 找到本轮真正的C位 |
| 驱动情感 | 愤怒、恐惧、执念 | 希望、信任、救赎 |
| 地位 | **唯一主线——游戏的脊柱** | 条件线——复仇成功后才有意义 |
| 失败后果 | 游戏失败（无论C位结果如何） | 游戏部分失败（但主线已赢，仍有结局） |
| 系统支撑 | 半记忆脉冲（核心系统） | 三轴观察（辅助系统） |
| 验证方式 | 一次性对质（不可撤销） | 累积式确信值（渐进验证） |

### 1.3 随机性原则

每个玩家进入游戏时，系统从固定角色池中随机分配：
- **1名个人孽缘**（从6名赎罪者中随机抽取）
- **1名个人C位**（从5名本命候选中随机抽取）

两个目标都是**隐藏的**——玩家不知道自己的孽缘是谁，也不知道自己的C位是谁。整个赛季的过程就是通过观察、推理、试错来锁定这两个人。

**关键设计：同一个偶像对不同玩家意味着不同身份。** Wyatt对玩家甲可能是孽缘，对玩家乙可能只是一个普通赎罪者；Milo对玩家丙可能是C位，对玩家丁可能只是个嫌疑对象。这让每个玩家的游戏体验完全不同。

### 1.4 为什么不是"识别全部赎罪者/全部本命"

设计上刻意避免"找出所有坏人/所有好人"的目标，原因：

- **聚焦感**：玩家只有2个明确目标（1孽缘+1C位），注意力不会被稀释到30人
- **错位陷阱**：玩家可能正确识别出"这是个赎罪者"但搞错了"这是不是我的孽缘"——识破类型不等于锁定个人
- **情感强度**：复仇的对象是"骗了你的人"而非"所有坏人"，守护的对象是"你的C位"而非"所有好人"——这种私人性让每场对质都带有强烈的情感重量

### 1.5 "复仇至上"的叙事内核

游戏的核心命题不是"你能找到好人吗"——而是**"你能识破坏人吗"**。

上一世的悲剧不是因为玩家没找到好人，而是因为玩家**没能识破坏人**。她把全部身家押在了一个表面完美的人身上，那个人塌房了，她失去了一切。重生的意义不是"再选一次"，而是"这次你能不能看穿伪装"。

因此，C位线被设计为复仇线的**延伸**而非平行线：
- 只有识破了孽缘的人，才具备了"分辨真假"的能力——这种能力是判断C位的前提
- 复仇过程中积累的观察经验、脉冲校准、认知失调管理，全部直接服务于C位判断
- 如果复仇失败（错杀好人或未找到孽缘），说明玩家的判断力未被校准——即使碰巧投对了C位，这种"正确"是不可靠的

> **设计宣言**：这个游戏不奖励"碰巧赌对"。它奖励"真正醒来"。

> 设计意图：救赎线概率 1/30 ≈ 3.3%，足够罕见以保持特殊性，又不至于需要刻意排除。

## 3. 主线：找到你的孽缘

### 3.1 目标定义

**找到那个在上一世欺骗你、令你一无所有的偶像。**

这是游戏的唯一主线。"找到"不是简单的"识别"——你需要：
1. **锁定**：确定30人中哪一个是你的孽缘（通过脉冲签名匹配+行为观察）
2. **对质**：在特定场景中与他正面交锋（消耗应援值触发对质事件）
3. **裁决**：对质后选择"揭穿"或"放过"

**对质是整个游戏最关键的不可逆决策。** 对质正确=主线胜利；对质错误或从未对质=主线失败，游戏进入失败结局（无论C位结果如何）。

### 3.2 线索来源

| 线索类型 | 来源 | 可靠性 | 消耗 |
|----------|------|--------|------|
| 直觉脉冲 | 面对与孽缘脉冲签名相似的角色时自动触发 | 中（有假阳性） | 不消耗资源，但受认知失调抑制 |
| 行为观察 | 在互动场景中仔细阅读角色的行为描写 | 高（但需要多次累积） | 应援值（解锁互动场景） |
| 赎罪者线索 | 练习量异常、等级与实力不符、其他角色反应 | 中（所有赎罪者都有，无法区分哪个是你的孽缘） | 时间（需要系统排查） |
| 对质试探 | 在对话中选择试探性选项，观察角色反应 | 高（孽缘会有特定的应激反应） | 好感度（试探会降低好感，可能关闭后续互动） |

### 3.3 对质机制

当玩家积累了足够证据，可以在角色互动场景中发起**对质**：

- 对质需要消耗**应援值**（金额随Phase推进递增：Phase 1需500、Phase 2需2000、Phase 3需5000）
- 对质后系统揭示该角色是否为你的孽缘
- **对质正确**（命中孽缘）：主线胜利。触发复仇剧情，孽缘被公开揭穿，该角色股价暴跌，你获得应援值返还+额外奖励。游戏进入"条件线解锁"状态——C位线现在有意义了
- **对质错误**（错杀好人）：**主线失败。** 被冤枉的角色好感度归零，该角色股价不跌反涨（"被迫害"效应），你损失全部对质投入且**认知失调值上升**。游戏进入失败结局——即使后续投对C位也是输
- **从未对质**（赛季结束前未发起对质）：**主线失败。** 你始终没能鼓起勇气面对真相，孽缘逍遥法外。游戏进入失败结局

> 设计意图：对质是不可逆的终极决策。玩家必须在"证据充分但永远不能100%确定"的状态下做出决断——这模拟了现实中"你永远无法完全确认一个人是否在骗你"的困境。犹豫不决和错杀好人同样致命。

### 3.4 对质的战略选择

对质不是"越早越好"：

| 时机 | 优势 | 风险 |
|------|------|------|
| Phase 1对质 | 孽缘股价低（如果是赎罪者，F级起步），对质后他来不及翻盘。如果正确，你有整个Phase 2-3来推进C位线 | 证据不足，假阳性高，容易错杀——一旦错杀，游戏直接失败 |
| Phase 2对质 | 证据累积更充分，假阳性降低。如果正确，仍有Phase 3来推进C位 | 孽缘可能已经升等级、涨股价，对质后你的回报降低。C位可能因你分心追孽缘而票数不足 |
| Phase 3对质 | 证据最充分，几乎不会错杀 | 如果孽缘已经进入前11名甚至出道组，对质后即使揭穿他也为时已晚——他可能已经影响了赛季格局。且留给C位线的时间几乎为零 |

### 3.5 "放过"选项——复仇的另一种形态

对质正确后，玩家可以选择：
- **揭穿**：公开孽缘的真面目，他退市淘汰。你获得复仇满足感+应援值返还。孽缘的威胁被永久消除
- **放过**：不揭穿，让他继续参赛。这同样是**主线胜利**——但代价不同

**放过的条件与后果**：
- 放过不是"算了"——放过意味着你**看清了他但选择不毁掉他**
- 放过后，孽缘继续留在赛季中，可能进入出道组，可能影响C位线的格局
- 放过后，玩家获得**"超越"状态**——认知失调值永久降低20点，半记忆系统在后续判定中灵敏度提升（对C位线有直接帮助）
- 但放过也意味着孽缘可能在Phase 2-3中继续作恶——如果他在后续触发塌房信号波及你的C位，风险自负

> 设计意图：在"复仇至上"的框架下，放过不是逃避复仇——而是"我已经看穿你了，你不再能伤害我"的超越。这是一种更高级的胜利形态，但它带来的风险（孽缘留在场上）让"放过"成为一种高难度选择而非"偷懒选项"。

### 3.6 认知失调——主线最大的敌人

认知失调系统是**主线的核心威胁**——它直接削弱玩家发现孽缘的能力：

- 每次玩家为可疑角色辩护（选择"他一定有苦衷"类选项），认知失调值上升
- 认知失调值越高，直觉脉冲越弱——感官叙事段落变得暗淡、频率降低
- 认知失调值达到阈值后，半记忆系统几乎完全失灵——玩家陷入和上一世一样的"自欺"状态

**在复仇至上的框架下，认知失调的后果被放大**：
- 脉冲失灵 = 无法锁定孽缘 = 主线失败
- 如果玩家为孽缘本人辩护（不知道他是孽缘），等于亲手保护了仇人
- 如果玩家为非孽缘角色辩护，虽然不会直接保护孽缘，但脉冲失灵会让他们无法分辨谁是孽缘

> 这是整个游戏最核心的心理机制——它模拟了现实中粉丝为偶像塌房辩护的真实心理过程。玩家的"重生"优势会被自己的认知失调侵蚀，如果走回老路，半记忆就会变成无用的残影，主线必然失败。

## 4. 条件线：找到你的C位

### 4.1 目标定义

**找到本轮真正的C位——唯一值得你押上全部身家的那个人。**

C位线是**条件线**——只有主线（复仇线）成功后，C位线才有意义。如果主线失败，C位线无论结果如何都视为失败。

"找到"意味着：
1. **识别**：从30人中锁定你的C位（通过三轴真心值观察+验证签名匹配）
2. **培养**：在赛季中持续投资他（买入股份、投票、组队加成）
3. **送出道**：在Phase 3最终投票中将他投为**第1名**（C位特指第1名，不是前5名中的任意一个）

### 4.2 C位线的激活条件

C位线在赛季开始时就**潜在存在**——玩家从第1周就可以开始观察和培养C位候选。但C位线的**胜负判定**取决于主线结果：

| 主线结果 | C位线状态 | 最终结局 |
|----------|-----------|----------|
| 主线胜利（对质正确） | C位线激活——胜负有效 | 视C位结果决定是金色还是银色结局 |
| 主线失败（对质错误/从未对质） | C位线无效——即使投对C位也判负 | 黑色结局（无论C位结果） |

> 设计意图：这意味着玩家不能"放弃复仇专心养C位"——那条路走到终点也是黑色结局。C位线不是一条可以独立胜利的线，它是复仇胜利后的"加试题"。

### 4.3 C位的判定标准

一个角色是你的C位，需要同时满足：
- **主线已胜利**（对质正确——这是前置条件）
- 他是你的**个人C位**（随机分配的本命候选）
- 你在Phase 3最终投票中将他投为**第1名**
- 他在Phase 3终局战中存活（未退市、未淘汰）

注意：你不需要"送5个人出道"——你只需要送对1个人到C位。其余4个出道名额可以是任何人。

### 4.4 验证机制

C位的验证是**累积式**的：

- 每次你在角色互动中正确观察到C位的验证签名，积累1点"确信值"
- 确信值达到阈值（3点）后，C位的真心值在你眼中变为"可见"——你可以在三轴下注界面看到他的真实数值范围
- 但即使确信值满了，你仍然可以选择不投他——系统不会强制你

**复仇主线对C位验证的加成**：
- 主线胜利后（无论揭穿还是放过），玩家的半记忆系统进入"校准状态"——脉冲不再困扰玩家（孽缘已锁定），残余的观察力和判断力全部可用于C位线
- 如果选择"放过"孽缘，"超越"状态提供的脉冲灵敏度提升会直接帮助C位验证——尤其当C位是Milo或Ash（假阳性脉冲角色）时，"超越"状态能压制假阳性让玩家看清真相
- 如果选择"揭穿"孽缘，应援值返还提供了更多资源来培养C位

> 设计意图：主线胜利不仅是"解锁"条件线，还直接为条件线提供资源加成。复仇越漂亮，C位线越好打。

### 4.5 C位认定的风险

即使主线胜利，送C位出道仍有风险：

| 风险 | 触发条件 | 后果 |
|------|----------|------|
| C位被退市 | C位股价在Phase 2跌至零（被你忽略太久、没买入股份护盘） | C位退赛，条件线失败→银色结局 |
| C位被淘汰 | C位在Phase 2结束时票数太低（你没投入足够投票） | C位不进入Phase 3，条件线失败→银色结局 |
| C位终局战失败 | C位在Phase 3个人终局战中落败（等级不足或属性被惩罚） | C位不进入最终投票→银色结局 |
| 被赎罪者挤掉 | 你送了赎罪者出道（被伪装欺骗），赎罪者占了一个出道名额但最终再次塌房 | 出道名额浪费，C位可能因此落选→银色结局 |
| 放过孽缘的连锁风险 | 你放过了孽缘，孽缘在Phase 2-3继续作恶，触发塌房信号波及C位 | C位被误伤→银色结局 |

## 5. 五大交织机制

主线的核心张力来自**追猎孽缘的过程中必然遇到C位线的问题，但玩家不知道哪些线索属于哪条线**。以下是五个让两条线"搅在一起"的机制：

### 5.1 证据歧义（Evidence Ambiguity）

**同一条行为线索可以同时被解读为"危险信号"和"安全信号"。**

| 观察 | 主线解读（这是我的孽缘吗？） | 条件线解读（这是我的C位吗？） |
|------|------------------------------|------------------------------|
| 舞台表现极强 | "他在用舞台魅力遮蔽低粉丝回馈——可能是我的孽缘" | "他舞台热忱高，可能是C位候选" |
| 对粉丝极好 | "他的粉丝回馈是伪装的——和上一世一模一样" | "他粉丝回馈高，符合C位标准" |
| 沉默寡言 | "沉默是掩护，和上一世的逃逸者一样" | "内敛型的真心，需要耐心观察" |
| 赎罪者气息 | "坠落者的味道——可能就是我的孽缘" | "经历过坠落的人可能有最纯粹的真心" |
| CP羁绊信号强 | "他在利用CP热度操纵股价" | "他能建立真实关系，CP羁绊值高" |

**在复仇至上的框架下**：玩家**应该**优先用主线框架解读线索——因为主线失败=全盘皆输。但问题在于，不是所有"危险信号"都指向孽缘（可能是假阳性），也不是所有"安全信号"都指向C位（可能是伪装）。如果玩家过度偏向主线框架，可能错杀C位（把C位的"真心信号"误读为"伪装信号"）；如果玩家过度偏向条件线框架，可能放过孽缘（把孽缘的"伪装信号"误读为"真心信号"）。

**文字游戏体现**：同一段行为描写文本在两种心态下读出完全不同的含义。系统不会标注"这是复仇线索"或"这是守护线索"——玩家必须自己判断当前应该用哪个框架解读。

### 5.2 资源竞争（Resource Competition）

玩家的**应援值**是有限资源，同时服务于两条线：

| 用途 | 服务于 | 消耗 | 优先级 |
|------|--------|------|--------|
| 解锁角色互动场景 | 主线（观察行为寻找孽缘）+ 条件线（观察验证签名） | 共享消耗 | 主线优先 |
| 买入偶像股份 | 条件线（为C位护盘）+ 主线（跟踪孽缘的股价异动） | 共享消耗 | 视情况 |
| 发起对质 | 主线专属 | 专属消耗 | **最高** |
| 最终投票 | 条件线专属（投C位第1名） | 专属消耗 | 仅主线胜利后有效 |
| 社区投票 | 两条线都需要（推C位上去/拉孽缘下来） | 共享消耗 | 视情况 |

**在复仇至上的框架下**：资源分配的默认优先级是主线。但设计上不强制——玩家可以"冒险"在Phase 1-2把资源倾斜到C位培养上（买入C位股份护盘、提前积累投票），赌的是后期主线对质时一击命中。如果赌对了，Phase 3既有主线胜利又有C位积累，可以直接冲金色结局。如果赌错了（对质错杀），前期投入C位的资源全部打水漂。

**核心矛盾**：你花在"调查谁是我的孽缘"上的应援值，就是你没法花在"培养我的C位"上的应援值。但如果不花在调查孽缘上，主线可能失败——全盘皆输。这是一个"必须先保住主线才能谈条件线"的资源博弈。

### 5.3 脉冲干扰（Pulse Interference）

半记忆脉冲系统是主线的核心工具，但它会**干扰**条件线：

**场景**：你的孽缘是Kai（舞台90/粉丝12）。Kai的脉冲签名是"舞台上燃烧下台后空了"。你的C位是Ash（T纪元，82/78/75）。Ash也在T纪元——最危险的纪元。

当你面对Ash时，你的脉冲会强烈闪烁——不是因为Ash是你的孽缘，而是因为：
1. Ash在T纪元，T纪元的"危险气息"会触发创伤记忆
2. Ash的脉冲强度本身是strong（假阳性）——T纪元环境带来的恐惧

**结果**：你的脉冲告诉你"Ash危险"，但真相是"Ash安全"。如果你信任脉冲放弃Ash，你的条件线就失败了。但如果你无视脉冲押注Ash——你可能犯了更致命的错误：万一同在T纪元的Kai才是你的孽缘，你因为无视脉冲而放过了真正的仇人，**主线失败**。

**在复仇至上的框架下**：脉冲干扰的后果更严重。如果玩家为了"不误判C位"而降低对脉冲的信任度，可能同时削弱了主线能力。脉冲是双刃剑——它是主线的唯一工具，但它的假阳性会干扰条件线。玩家不能简单地"信脉冲"或"不信脉冲"——必须学会**区分脉冲的来源**（是孽缘触发的真脉冲，还是T纪元环境的假阳性）。

**文字游戏体现**：脉冲以叙述文字呈现——"你的心跳加速，手指发凉。一种说不清的恐惧从胃部升起，像是某种你不想记住的记忆正在试图浮出水面。" 玩家需要在阅读这段文字后做出选择：信任直觉还是信任理性？

### 5.4 辩护陷阱（Defense Trap）

认知失调系统是主线最大的敌人，同时它与条件线形成矛盾：

**机制**：当玩家为一个可疑角色辩护（选择"他一定有苦衷"类选项）时：
1. 认知失调值上升
2. 直觉脉冲灵敏度下降（**主线被直接削弱**）
3. **同时**：该角色的好感度上升，解锁更多互动场景

**主线下**：
- 如果被辩护的角色是你的孽缘——灾难！你亲手削弱了发现他的能力，主线可能因此失败
- 辩护孽缘等于"走回上一世的老路"——上一世你也是为那个人找借口，直到一切崩塌

**条件线下**：
- 如果被辩护的角色是你的C位——辩护带来的好感度提升能解锁更多验证签名，条件线被加强
- 但为此付出的代价是脉冲灵敏度下降——主线被削弱

**在复仇至上的框架下**：辩护陷阱的后果被放大。为C位辩护虽然在条件线上有益，但如果因此导致脉冲失灵、无法锁定孽缘，全盘皆输。玩家不能"为了培养C位而辩护可疑角色"——因为那个"可疑角色"可能是孽缘。

**文字游戏体现**：对话选项中，"辩护类"选项通常是"看起来善良"的选择。系统不标注"这是辩护行为"——它只是一个看起来合理的对话选择。玩家可能在没有意识到的情况下反复触发认知失调，等意识到时脉冲已经几乎沉默了。

### 5.5 CP纠缠（CP Entanglement）

如果孽缘和C位之间存在CP关系，两条线会通过CP事件互相干扰：

| 孽缘 | C位 | CP关系 | 纠缠效果 |
|------|-----|--------|----------|
| Kai | Milo | Milo→Kai (82) | 你要守护Milo但Milo的全部注意力都在Kai身上——观察Milo的CP信号必然同时观察Kai |
| Kai | Ash | Ash→Milo→Kai (间接) | Ash关注Milo，Milo关注Kai——三层CP链让T纪元信号极度混乱 |
| Wyatt | Sven | Sven→Wyatt (76) | Sven的CP羁绊信号最强（76指向Wyatt），但Wyatt是利用Sven——观察Sven的真心必须面对他的孽缘 |
| Orion | Ian | Ian→Orion (88) | Ian的CP羁绊值全30人最高（88指向Orion），验证Ian的C位签名必须观察他与Orion的互动 |
| Clark | Leon | Leon→Miles (78，间接) | Clark会在Leon练习时走廊旁观——两人空间上有交集 |

**最致命的纠缠**：孽缘=Kai + C位=Milo
- Milo对Kai有82的深层羁绊，是全游戏最强CP线之一
- 你要培养Milo（C位），但Milo在拼命守护Kai（孽缘）
- 你要揭穿Kai（主线），但揭穿Kai会让Milo崩溃——你的C位可能因此状态暴跌
- Milo的CP羁绊信号（验证签名之一）全部指向Kai——你在观察Milo的真心时必然同时面对Kai

**在复仇至上的框架下**：CP纠缠的后果是——如果你为了保护C位（不被孽缘的塌房波及）而延迟对质孽缘，你可能错过主线的最佳窗口期。反之，如果你果断对质孽缘，CP纠缠可能导致C位受连累。这是"主线优先"与"条件线保底"之间的终极博弈。

> 设计意图：CP纠缠让"复仇优先"的决策在某些组合下变得极为痛苦——你必须在对质孽缘和保全C位之间做出取舍。

## 6. 分阶段演进

### 6.1 Phase 1：等级评价（第1-2周）— 追猎开始

**主线状态**：全面展开。玩家面对30个陌生面孔，脉冲零星闪烁，每一条线索都可能指向孽缘。

**条件线状态**：潜伏存在。玩家可以同时观察C位候选，但主线压力下资源紧张。

| 维度 | 主线（复仇） | 条件线（C位） | 主线优先度 |
|------|-------------|---------------|-----------|
| 脉冲 | 零星且微弱，难以判断真伪——但这是唯一的起点 | 无直接影响 | **核心** |
| 三轴 | 几乎无法获取（需要多轮互动） | 初始校准中 | 共享 |
| 应援值 | 紧张（需要解锁大量互动场景来排查孽缘） | 同样紧张但被主线挤压 | **主线优先** |
| CP | 几乎无信号（角色还未深入互动） | 几乎无信号 | — |
| 目标 | "30人里谁有危险气息？" | "30人里谁有真心信号？"（次要） | 主线主导 |

**Phase 1的核心体验**：追猎的焦虑。玩家需要在信息不足的情况下建立孽缘的"嫌疑人名单"。脉冲是唯一的超自然工具，但它零星、模糊、有假阳性。玩家会同时积累大量"可疑"和"有希望"的信号，但必须优先用主线框架筛选——因为Phase 1结束时，如果玩家连孽缘的候选人范围都没缩小，Phase 2的博弈将极其被动。

**文字游戏体现**：Phase 1以**叙事场景**为主——玩家阅读30个角色的首次登场描写、初次互动对话、练习室观察笔记。每段文字都精心设计为"可被两种框架解读"，但脉冲段落（感官叙事）会暗示"这个角色可能与你的过去有关"。系统在Phase 1结束时给出排位，但不给出任何关于孽缘或C位的直接提示。

### 6.2 Phase 2：策略对战（第3-6周）— 博弈与抉择

**主线状态**：证据累积加速，脉冲频率上升。玩家应该已缩小孽缘候选人至3-5人。对质的时机窗口打开。

**条件线状态**：如果主线进展顺利，玩家有余力开始C位培养。但如果主线受阻（认知失调高、候选人仍未收窄），条件线被挤压。

| 维度 | 主线（复仇） | 条件线（C位） | 主线优先度 |
|------|-------------|---------------|-----------|
| 脉冲 | 频率上升（接触增多），但认知失调风险最大 | 间接影响（脉冲干扰C位判断） | **核心** |
| 三轴 | 通过对战表现可推断某些轴值 | 通过对战可验证C位的三轴高低 | 共享 |
| 应援值 | 需要在对质和护盘间分配 | 需要在投票和互动间分配 | **主线优先** |
| CP | CP羁绊加成在对战中显化——可验证CP值 | CP信号是J纪元C位验证的关键 | 视组合 |
| 塌房信号 | 塌房信号触发=孽缘暴露的最佳窗口 | 塌房信号可能误伤C位（假阳性） | **主线窗口** |

**Phase 2的核心体验**：对质的压力。玩家在前4周积累的证据是否足够发起对质？如果对质太早，可能错杀好人——主线失败。如果对质太晚，孽缘可能已经混进前11名，C位也可能因资源不足被淘汰。

**关键节点**：
- **第3周**：首次策略对战。对战中某些角色的表现会暴露三轴信号——舞台热忱通过表演质量暴露，粉丝回馈通过签售对战暴露，CP羁绊通过羁绊加成暴露。
- **第4周**：第一次塌房信号可能触发。如果孽缘的某轴极低（如Kai的粉丝12），他可能在无镜头场景中暴露——这是主线的黄金窗口，也是发起对质的最佳时机。
- **第5周**：社区投票第一轮。玩家的应援值在投票中消耗——是推C位上去还是拉孽缘下来？**主线优先意味着：如果有证据指向孽缘，拉他下来比推C位上去更重要。**
- **第6周**：Phase 2结束，30人淘汰至11人。如果孽缘在此阶段被自然淘汰（票数过低或触发退市），**系统判定为主线"被动胜利"**——孽缘被赛季机制淘汰，但玩家未发起对质，属于"未对质"的主线失败（因为玩家没有主动面对真相）。

**被动淘汰规则**：孽缘被赛季机制淘汰≠主线胜利。主线胜利要求玩家**主动对质并命中**。如果孽缘被淘汰但玩家从未对质过，主线仍判失败——因为玩家从未真正"面对"自己的过去。

### 6.3 Phase 3：总决赛（第7-8周）— 终局裁决

**主线状态**：如果Phase 2已对质成功，Phase 3全力推进条件线。如果未对质，Phase 3是最后机会——但证据最充分也最危险。

**条件线状态**：如果主线已胜利，Phase 3是C位线的冲刺阶段。如果主线未决，条件线处于"悬置"状态——玩家可以同时推进，但知道如果主线失败一切归零。

| 维度 | 主线（复仇） | 条件线（C位） | 主线优先度 |
|------|-------------|---------------|-----------|
| 脉冲 | 如果认知失调低，半记忆觉醒——脉冲形成具体碎片 | 觉醒的脉冲可能直接揭示C位的验证签名 | **核心**（如未对质） |
| 三轴 | 不再需要（对质或已完成） | 确信值应已满，C位三轴可见 | 条件线主导（如主线已胜） |
| 应援值 | 最终对质（如未对质过）需5000 | 最终投票需全部应援值 | 视主线状态 |
| CP | CP线在终局战中提供最终加成 | C位+CP搭档组合可能提供最强战力 | 视组合 |
| 目标 | 对质或放弃（最后机会） | 投票C位为第1名 | **决断时刻** |

**Phase 3的核心体验**：
- **如果主线已胜利**：孤注一掷冲C位。前6周积累的观察经验+主线胜利后的资源返还+"超越"状态（如果放过）全部投入C位冲刺。这是游戏最顺畅的路径——但也是最考验前期C位培养是否到位的路径。
- **如果主线未决**：最痛苦的抉择。你必须在Phase 3同时对质孽缘（消耗5000应援值）和投票C位（消耗全部应援值）。资源几乎不可能同时满足——你必须做出取舍。**而取舍的默认答案是：主线优先。**

**半记忆觉醒**：如果玩家在赛季中保持低认知失调值（没有过多为可疑角色辩护），Phase 3的半记忆会觉醒：
- 脉冲不再是模糊的"感觉"，而是形成具体的**记忆碎片**——文字段落描述上一世的某个瞬间
- 记忆碎片包含孽缘的特定细节（但不直接说名字），如"你记起了那双手——签售时握你的手力度恰好，像是量过的"
- 玩家需要将记忆碎片与当前赛季的观察匹配，完成最后的锁定

**半记忆沉默**：如果认知失调值过高，半记忆在Phase 3完全沉默——玩家失去主线的终极辅助，只能靠Phase 1-2积累的理性判断。主线难度大幅上升，失败概率极高。

## 8. 结局矩阵

### 8.1 结局结构（复仇至上）

| | 条件线成功（投对C位为第1名） | 条件线失败（投错/C位被淘汰） |
|---|---|---|
| **主线胜利**（对质命中孽缘） | **金色结局：改写命运** | **银色结局：复仇的代价** |
| **主线失败**（对质错误/从未对质/孽缘被动淘汰） | **黑色结局：虚妄的救赎** | **黑色结局：重蹈覆辙** |

> 核心变化：原"铜色结局"（守护成功+复仇失败）被降级为**黑色结局：虚妄的救赎**——主线失败时即使投对C位也是输。

### 8.2 结局详情

**金色结局：改写命运**
- 条件：主线胜利（对质命中孽缘） + C位送出道为第1名
- 叙述：你揭穿了上一世的仇人，同时找到了真正值得信任的人。半记忆在觉醒后终于安静——你不再被过去束缚。C位出道，你在观众席上看着他在舞台上燃烧，这一次你选对了。不是因为运气，而是因为你终于学会了分辨真假。
- 奖励：全成就解锁，应援值全额返还（可用于New Game+），解锁"孽缘档案"——告诉你上一世到底发生了什么
- 概率预估：需要主线+条件线双胜，综合概率约20-30%

**银色结局：复仇的代价**
- 条件：主线胜利（对质命中孽缘） + C位送出道失败（投错/被淘汰）
- 叙述：你复仇了。孽缘被揭穿，当众退市。但你在复仇上投入了太多，没来得及为C位积攒足够的票数。C位在11进5时被淘汰，或是你的最终投票投错了人。你赢了复仇，但输了未来。半记忆在觉醒后告诉你"你选错了那个人"，但你已经没有机会重来。
- 效果：苦涩的胜利——复仇的满足感被守护失败的遗憾冲淡。但这是**胜利的结局**——只是不完美。
- 概率预估：主线胜利但条件线失败，综合概率约15-25%

**黑色结局：虚妄的救赎**
- 条件：主线失败（对质错误/从未对质/孽缘被动淘汰） + C位送出道为第1名
- 叙述：你没找到仇人。或者你找错了人，冤枉了一个好人。但你把全部身家投在了一个看起来真心的人身上——他出道了，成了C位。所有人都说你选对了。但你心里知道：你并没有真正"看见"他。你只是碰巧赌对了，就像上一世你碰巧赌错了一样。你的判断力从未被校准。下一世，你可能还会选错。
- 效果：最讽刺的结局——表面成功，内在失败。玩家"看起来赢了"但实际上"什么都没学到"。孽缘仍然逍遥法外，可能在出道组中继续伪装。
- 概率预估：主线失败但碰巧投对C位，综合概率约5-10%

**黑色结局：重蹈覆辙**
- 条件：主线失败 + 条件线失败
- 叙述：你既没有找到仇人，也没有找到值得信任的人。最终投票投给了错误的人——一个赎罪者混入了出道组，未来必将再次塌房。半记忆在终局完全沉默，像是你又一次蒙蔽了自己。一切重演。
- 效果：最黑暗的结局——暗示玩家的"重生"并没有改变任何事
- 概率预估：双线失败，综合概率约35-50%（最常见的结局——因为游戏很难）

### 8.3 特殊结局：救赎线

**当孽缘=C位=Milo时**，结局矩阵被特殊结局替代：

- **如果玩家选择对质Milo（揭穿）**：Milo被揭穿为"孽缘"，退市淘汰。主线胜利。但他也是你的C位——C位已退市，条件线自动失败。→ **银色结局·变体：亲手杀死希望**——你赢了复仇，但你亲手毁掉了唯一的救赎。半记忆碎片最终浮现："那张脸……和上一世不一样。上一世的那个人，他的笑是假的。这个人的笑，是真的。但你已经把他杀了。"

- **如果玩家选择对质Milo（放过）**：Milo继续参赛。主线胜利（放过=看穿但不毁掉）。你可以投他出道作为C位。如果投对→**金色结局·变体：原谅**——你原谅了上一世的仇人（虽然他其实不是上一世的仇人，他只是长得像），你找到了真正的C位。半记忆碎片最终浮现："我想起来了……上一世的那个人，和这一世的这个人，不是同一个人。我一直分不清。但现在我分清了。"→ 这是全游戏最完美的结局。

- **如果玩家选择不对质Milo**：主线失败。无论C位结果如何→黑色结局。你没有勇气面对真相——而真相是，你的"仇人"可能根本不是你的仇人。

- **如果玩家对质了错误的人**：主线失败。→ 黑色结局。你以为是Milo，但Milo不是你的孽缘——你的孽缘是另一个人，你因为被Milo的假阳性迷惑而错过了真正的目标。

> 设计意图：救赎线是整个游戏最复杂、最情感化的体验，概率仅3.3%。它测试的不是"能不能找到坏人"——而是"能不能分辨坏人和好人"。

## 9. 文字游戏系统适配

### 9.1 形态转换总则

原设计的Phaser.js视觉管线全部替换为**文字叙事驱动**：

| 原系统 | 视觉游戏形态 | 文字游戏形态 |
|--------|-------------|-------------|
| 四纪元视觉差异 | Fragment Shader实时渲染 | 文字风格差异（用词、句式、节奏、意象） |
| 微表情系统 | Spritesheet关键帧动画 | 行为描写文本（精确到秒的微动作描述） |
| 直觉脉冲 | 画面边缘红色径向渐变 | 感官叙事段落（触觉/嗅觉/心跳/不安） |
| 观察模式 | "快速浏览"vs"仔细观察"切换 | 阅读深度选择（概览文本vs展开细节） |
| 偶像大A市场 | K线图+实时渲染 | 文字播报+表格UI |
| CP互动 | 角色立绘+动作同步动画 | 对话场景+空间关系描写 |
| 塌房信号 | 视觉特效+股价暴跌动画 | 突发新闻文本+市场播报 |
| 对质 | 视觉特效+角色立绘变化 | 独占叙事段落（全屏文本，不可撤销确认） |

### 9.2 四纪元文字风格

每个纪元的行为描写使用截然不同的文字风格，让玩家通过"阅读体验"就能感受到纪元差异：

**C纪元——冷峻克制体**
- 句式：短句为主，平均8-15字/句。主谓宾结构完整，修饰语极少。
- 节奏：匀速，无停顿。读起来像在读报告。
- 意象：金属、冷光、直线、几何。
- 示例："Leon走进练习室。灯已经亮了。他站到标记点上。走位开始。三步，转身，停顿，回望。精确。没有多余的动作。灯光打在他脸上的时候，瞳孔微微放大——如果有人在这一刻看他的眼睛，会发现那不是空洞，是聚焦。"

**K纪元——情绪外放体**
- 句式：长短交替，情绪高潮时使用长句（30-50字），平静时回归中等句。
- 节奏：变速。时而急促（情绪爆发），时而舒缓（柔软时刻）。
- 意象：暖色、光晕、液体、温度。
- 示例："Wyatt的笑容在灯光下绽开的时候，你几乎能感觉到暖意——不是比喻，是物理性的，像是有人在你面前点了一盏灯。他握住粉丝的手，力度恰到好处，拇指轻轻搭在手背上，琥珀色的眼睛弯成月牙，每一根睫毛都在发光。太完美了。完美到你的胃里升起一阵说不清的不安。"

**J纪元——沉默留白体**
- 句式：极短句+大量省略。对话最少，描写最多。句子之间大量留白（段落间空行）。
- 节奏：极慢。读者被强迫减速。
- 意象：窗帘、光斑、距离、沉默。
- 示例："Ian坐在窗边。\n\n光透过窗帘，把他的轮廓描得很模糊。\n\n有人在他左边坐下了。他的身体转了2度。很小的角度。他自己可能都没注意到。\n\n但他转了。"

**T纪元——极端断裂体**
- 句式：断裂。一句中间可能突然切换视角或情绪。感叹号和破折号频繁。
- 节奏：不规律。短促的爆发后跟突然的静默。
- 意象：火、黑暗、裂痕、闪电。
- 示例："Kai在舞台上的那一刻——燃烧。没有别的词。他不是在表演，他是在把什么东西全部倒出来，灯光打在他身上像是打在火上。汗珠从颧骨滑落。走位有野性的即兴。然后灯灭了。0.05秒。他的眼神变成完全空洞的。再亮起来的时候，又是燃烧。哪一个是他？也许两个都是。也许两个都不是。"

### 9.3 观察系统——阅读深度

文字游戏的核心交互是**阅读深度选择**：

**概览模式（快速浏览）**
- 每个角色在场景中的描写以1-2句概述呈现
- 适合在Phase 1初期的"30人大扫描"中使用
- 消耗极少量应援值（或免费）
- 只能看到表层信号——"他在笑""她没说话""他走位精准"
- **关键设计**：概览模式下，微表情信号几乎不可见。玩家如果只用概览模式，会错过所有验证签名和脉冲线索

**观察模式（仔细阅读）**
- 解锁该角色的完整行为描写段落（200-500字）
- 消耗应援值（Phase 1每次50、Phase 2每次200、Phase 3每次500）
- 可以看到微表情细节——"嘴角上扬的角度每次都一模一样""瞳孔在灯光下自然放大""身体无意识转向2度"
- 在观察模式下，脉冲系统才会真正激活——玩家的直觉以感官叙事段落插入

**对质/试探模式**
- 在互动对话中选择特定选项，触发角色的应激反应
- 消耗好感度（可能关闭后续互动）
- 孽缘会有独特的应激描写——"他的手停了0.3秒才继续签名""笑容没变但声音低了半个调""眼神闪了一下，很快，如果你没在观察模式就不会注意到"

**对质模式（独占叙事）**
- 发起对质时进入全屏独占叙事段落
- 文本长度500-1000字，描写玩家与目标角色的正面交锋
- 对质正确：孽缘的伪装在文字中被逐层剥开——"他的笑容终于碎了。不是崩塌，是像一面镜子从中间裂开，裂缝两边是两张完全不同的脸。"
- 对质错误：被冤枉角色的真实反应——"他看着你的眼神里没有愤怒，只有一种……悲伤。像是他早就知道会有人这样对他。"
- 对质后弹出不可撤销的确认——"确认对质结果？此操作不可逆。"

### 9.4 直觉脉冲——文字形态

脉冲不再是视觉特效，而是**插入式感官叙事**：

**weak（微弱）**
- 插入1句感官描写："你的后颈微微一凉。"
- 不影响阅读流，玩家可能忽略

**medium（中等）**
- 插入2-3句感官段落："你的心跳突然加速。不是害怕——更像是某种你不想记住的东西正在试图浮出水面。手指尖有一点发麻。"
- 轻微打断阅读流，提示玩家"这里有信号"

**strong（强烈）**
- 插入完整段落（4-6句）："胃部紧缩。一种特定的气味闪过——不是当前场景的气味，是记忆里的。像是……舞台后台的化妆间？混着廉价咖啡和发胶的味道。你的手开始发抖。你想不起来这是什么地方，但你的身体记得。"
- 强烈打断阅读流，强制玩家注意

**extreme（极强）**
- 插入半记忆碎片（8-10句），包含上一世的模糊画面："光。很亮的光。有人在台上。那个身影——你认识那个身影。他转身的方式，他笑的弧度，他谢幕时停留的时间。你见过。不是在这一世。是在——在——画面碎裂了。你只记得一种感觉：被抛弃。所有的信任，所有的应援，所有的钱，全部——碎裂。然后是坠落的感觉。物理性的坠落。风。地面。"
- 几乎占据整个阅读段落，玩家被强制拉入半记忆体验

### 9.6 CP互动——文字形态

CP关系通过**场景叙事**而非动画呈现：

当两个有CP关系的角色在同一场景中出现时，系统会在他们的行为描写中插入**同步信号**：

```
练习室。Ian和Orion同时在场。

Ian坐在窗边。Orion站在门口——他刚才从T纪元的走廊走过来，手里没有书。

Ian的身体转了2度。指向Orion的方向。

Orion没有看他。Orion在看窗外。但他的呼吸频率变了——
从每分钟14次变成了12次。更慢。更沉。

他们之间隔着五米的距离，但空气的密度似乎变了。
不是暧昧。是某种更深的、两个人都不说破的东西。
```

玩家需要在阅读中捕捉这些同步信号——"身体转向""呼吸频率变化""距离缩短"——来判断CP羁绊值。J纪元C位（Ian）的验证签名（"有人坐下时身体转向"）就隐藏在这种场景叙事中。

### 10.2 主线结果判定逻辑

```
function resolveMainQuest(player): MainQuestResult {
  if (player.confrontationStatus === 'correct') {
    // 对质命中孽缘
    if (player.choseReveal) return 'victory_reveal'    // 揭穿
    if (player.choseSpare) return 'victory_spare'     // 放过
  }
  if (player.confrontationStatus === 'wrong') {
    return 'failure_wrong'  // 错杀好人
  }
  if (player.confrontationStatus === 'none') {
    // 从未对质
    if (player.sinnerWasEliminated) return 'failure_passive'  // 孽缘被被动淘汰
    return 'failure_none'  // 孽缘仍在场上，玩家从未面对
  }
}

function resolveEnding(player): EndingType {
  const mainResult = player.mainQuestResult
  const condResult = player.conditionQuestResult

  // 主线失败 = 黑色结局（无论条件线结果）
  if (mainResult.startsWith('failure')) {
    if (condResult === 'success') return 'dark_illusion'  // 虚妄的救赎
    return 'dark_repeat'  // 重蹈覆辙
  }

  // 主线胜利 = 视条件线结果
  if (mainResult.startsWith('victory')) {
    if (condResult === 'success') return 'golden'  // 改写命运
    return 'silver'  // 复仇的代价
  }
}
```

### 10.5 随机生成算法

```
function generateQuests(): { sinner, center, isRedemption } {
  const sinners = ['Clark', 'Wyatt', 'Jade', 'Orion', 'Kai', 'Milo']
  const centers = ['Leon', 'Sven', 'Ian', 'Milo', 'Ash']

  const sinner = randomChoice(sinners)      // 1/6
  const center = randomChoice(centers)     // 1/5

  const isRedemption = (sinner === 'Milo' && center === 'Milo')

  return { sinner, center, isRedemption }
}
```

- 救赎线（Milo×Milo）：1/30 ≈ 3.3%
- 孽缘=Milo（非救赎线）：5/30 ≈ 16.7%
- C位=Milo（非救赎线）：5/30 ≈ 16.7%
