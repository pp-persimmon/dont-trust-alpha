## 赢的定义

**金色结局 = 主线胜利 + 条件线成功**

| 条件 | 要求 |
|------|------|
| 主线胜利 | 主动对质并命中你的个人孽缘（3次机会中至少1次命中） |
| 条件线成功 | 主线胜利后，在Phase 3最终投票中将你的个人C位投为第1名，且C位在终局战中存活 |

缺任何一个 = 不是金色结局。主线失败时条件线无意义（黑色结局）。

## 赢的四个阶段

### 阶段一：Phase 1（第1-2周）—— 免费扫描，建立嫌疑人名单

**你要做的事**：

1. **免费扫描全部30人**。Phase 1概览模式完全免费，每个角色首次观察也免费。这是你唯一不花钱就能收集信息的机会。

2. **记录脉冲触发**。每次阅读角色描写时，留意是否插入了感官叙事段落（"后颈发凉""心跳加速""胃部紧缩"）。这些就是脉冲触发。把触发过脉冲的角色记进证据板的嫌疑人名单。

3. **不要辩护**。Phase 1的对话中会出现"他一定有苦衷"之类的选项——不要选。每次辩护认知失调+5~10，脉冲灵敏度下降。Phase 1你需要脉冲全开状态来扫描。

4. **不要急于对质**。Phase 1证据不足，假阳性高。除非你的脉冲在某个角色身上达到extreme级别且行为线索完全匹配，否则把对质机会留到Phase 2。

5. **初步给C位候选人们买入少量股份**。不需要多，每人数十股即可。这是"护盘"——防止C位在Phase 1因股价过低被标记为退市风险。

**Phase 1结束时你应该有**：
- 一份6-10人的嫌疑人名单（触发过脉冲的角色）
- 一份3-5人的"有希望"名单（行为描写中有真心信号的角色）
- 两个名单可能有交集——这很正常，Phase 1就是分不清
- 每个C位候选手上有少量股份

**关键纪律**：Phase 1结束时不要用对质。如果忍不住想用，记住——你只有3次机会，Phase 1的假阳性率最高，浪费在这里最不值。

---

### 阶段二：Phase 2（第3-6周）—— 收网对质，确认孽缘

**你要做的事**：

1. **用观察模式集中调查嫌疑人名单**。Phase 2观察成本降为150/次。把应援值优先花在Phase 1脉冲触发最强的3-5人身上。你需要看到他们的完整行为描写（200-500字），寻找与脉冲签名匹配的细节。

2. **利用假阳性自动排除**。Phase 2开始后，部分假阳性角色会因行为差异自动暴露——Penn因等级过低、Ruby因情绪波动真实、Blaze因连续失误、Blair因CP值为0。证据板会自动将这些角色移入"已排除"。

3. **对质试探**。在嫌疑人的互动对话中选择试探性选项（不发起正式对质，只是试探）。孽缘会有独特的应激反应——"手停了0.3秒才继续""笑容没变但声音低了半个调"。这些反应在观察模式中才能看到。

4. **发起对质（最佳时机：第4-5周）**。当你满足以下条件时发起对质：
   - 证据板上某角色的信心值≥60
   - 至少2条行为线索匹配脉冲签名
   - 对质试探中有明确应激反应
   - 如果以上条件全满足，命中的概率约75-85%

5. **对质命中后的选择**：
   - **揭穿**：孽缘退市，你获得应援值返还+额外奖励。资源充裕，C位线好打。
   - **放过**：孽缘留在场上，你获得"超越"状态（脉冲灵敏度提升），但孽缘可能后续作恶波及C位。
   - **建议**：如果孽缘和C位有CP纠缠关系（如孽缘=Kai、C位=Milo），选择放过更安全——揭穿Kai会让Milo崩溃。如果没有CP纠缠，揭穿更干净。

6. **同步推进C位**。如果你在Phase 2前期就完成了对质，剩下的时间全力培养C位——继续买入股份、参与社区投票推C位上去。

**Phase 2结束时你应该有**：
- 主线已胜利（对质命中），或至少已用1次对质排除1-2个嫌疑人
- C位候选的股价和票数稳定在前11名内
- 认知失调值控制在40以下（如果你没有过度辩护）

**如果Phase 2结束时仍未对质**：不要慌。Phase 3脉冲最清晰，你有2次对质机会剩余。但孽缘可能已经混进前11名，风险上升。

---

### 阶段三：Phase 3（第7-8周）—— 终局裁决 + C位冲刺

**你要做的事**：

1. **如果主线已胜利**：全力冲C位。
   - 确信值应已达3点（Phase 1-2积累），C位三轴对你可见
   - 确认C位在终局战中存活（等级足够、属性未被惩罚）
   - 将全部剩余应援值投入最终投票，将C位投为第1名
   - 如果选择了"放过"孽缘，留意他是否在Phase 3触发塌房信号波及C位——如有，紧急买入C位股份护盘

2. **如果主线未决**：你必须同时对质+投票，资源极紧张。
   - **先对质**。Phase 3的脉冲最强且最精确——extreme碎片会包含具体辨识线索（手部细节、谢幕习惯、笑的弧度）。将碎片与Phase 1-2的行为观察交叉验证。
   - 对质成本5000应援值。命中后应援值返还部分可投入投票。
   - 如果Phase 3对质仍未命中（第2次或第3次错杀），且孽缘在前11名中——主线可能失败。但如果你之前2次都错杀了不同的人，证据板上已排除2人，搜索范围缩小，第3次命中的概率更高。

3. **半记忆觉醒检查**。如果你整个赛季认知失调值保持在30以下：
   - Phase 3的半记忆完全觉醒——脉冲形成清晰的记忆碎片
   - 记忆碎片包含孽缘的特定细节（不直接说名字）
   - 将碎片与证据板上的行为线索交叉匹配，完成最后锁定

4. **最终投票**。这是不可逆的。把你全部应援值投给你认为的C位。投对了=金色结局。投错了=银色结局。

### 阶段四：结局判定

系统按以下逻辑判定你的结局：

```
主线对质命中了吗？
├─ 是 → 主线胜利
│   ├─ C位投对第1名了吗？
│   │   ├─ 是 → 金色结局 ✓
│   │   └─ 否 → 银色结局
│   └─ （如果放过孽缘，孽缘后续波及C位导致C位失败 → 银色结局）
└─ 否 → 主线失败
    ├─ 孽缘被赛季自然淘汰了吗？
    │   ├─ 是 → 被动胜利
    │   │   ├─ C位投对 → 银色变体
    │   │   └─ C位投错 → 银色变体（空洞）
    │   └─ 否 → 主线彻底失败
    │       ├─ C位投对 → 黑色·虚妄
    │       └─ C位投错 → 黑色·重蹈
```

## 赢的核心心法

### 心法一：脉冲是你的指南针，但它会骗你

脉冲是唯一能告诉你"这个人可能与你的过去有关"的工具。但它有两个缺陷：假阳性（会误判无辜的人）和认知失调抑制（你辩护多了它就失灵）。

**正确用法**：
- 用脉冲缩小范围（谁触发了脉冲=谁值得调查）
- 用行为观察确认（脉冲触发后，去读他的完整描写找匹配细节）
- 用对质试探最终验证（应激反应是最硬的证据）
- **不要只靠脉冲就发起对质**——假阳性会让你的3次机会白白浪费

### 心法二：不要辩护

整个游戏最致命的陷阱。辩护类选项看起来是"善良的选择"，实际上每次都在：
- 削弱你的脉冲（认知失调+5~10）
- 让你走回上一世的老路（上一世你就是为那个人找借口直到一切崩塌）

**如果你发现自己已经辩护了几次**：
- 立刻停止
- 在休息场景中选择"自省"（消耗1天+100应援值，认知失调-15）
- 整个赛季最多自省3次，不要浪费

### 心法三：资源分配的主线优先原则

应援值是有限资源。默认优先投入主线（调查孽缘），原因：
- 主线失败=全盘皆输，C位投入全部打水漂
- 主线胜利后应援值有返还，可以转投C位

**例外**：如果你在Phase 1就通过脉冲+行为锁定了孽缘（信心值≥70），可以在Phase 2大胆对质，然后Phase 2后半段到Phase 3全力C位。这是最优路径——但需要运气和判断力。

### 心法四：越到后期越清晰

Phase 1的脉冲是weak，你可能注意不到。Phase 2开始medium，假阳性开始自动排除。Phase 3的脉冲是strong到extreme，且碎片包含可交叉验证的具体细节。

**这意味着**：如果你不确定，等。晚对质比早对质安全。但不要等到赛季结束——从未对质=主线失败。

### 心法五：证据板是你的外脑

不要靠记忆。30人的信息量人类大脑无法全部记住。证据板自动归集了你触发过的脉冲、观察到的行为线索、对质试探的应激反应，并给出信心值。

**但注意**：信心值高不等于一定是孽缘。如果全是假阳性脉冲堆出来的高分，对质就会错杀。在发起对质前，检查这个角色的信心值来源——如果"行为线索匹配"和"应激反应"的分值占比高（而不是纯脉冲堆分），命中概率更高。

### 心法六：C位不是"选最好的"，是"选你的"

5名本命候选三轴全高，从数据上看都是"好人"。但只有1个是你的C位。你不能通过"谁三轴最高"来判断——你需要的是验证签名。

**验证签名**是你判断C位的唯一可靠依据：
- Leon：谢幕时多停留0.5秒看最后一排
- Sven：表演后走到粉丝席最角落点头
- Ian：有人靠近时身体无意识转向2-3度
- Milo：赎罪者身份下三轴全高的矛盾
- Ash：T纪元极端环境中"不极端"的稳定性

每个C位的验证签名需要在特定的场景中、用观察模式才能看到。如果你从Phase 1就在有意识地收集这些信号，到Phase 3确信值自然满3点，C位三轴可见。

### 心法七：CP纠缠是双刃剑

如果你的孽缘和C位有CP关系，你无法只看一个不看另一个。但这也可以利用：
- 观察C位的CP信号时必然同时接触孽缘——孽缘的行为暴露在你的视野中
- 如果你选择"放过"孽缘，CP纠缠不会断裂，C位不会因孽缘被揭穿而崩溃
- 最难组合（孽缘=Kai、C位=Milo）的破法：利用Milo对Kai的82羁绊——观察Milo的CP信号时，你同时在看Kai的粉丝回馈暴露（12分极低，Phase 2后无可掩饰）

## 最优通关路线（理想情况）

| 时间 | 行动 | 资源消耗 |
|------|------|----------|
| 第1周 | 免费扫描30人，记录脉冲触发，给5个C位候选各买20股 | 0（扫描免费）+1000（股份） |
| 第2周 | 对脉冲触发最强的5人做观察模式，试探对话 | 150×5=750 |
| 第3周 | 首次策略对战，观察三轴信号，排除部分假阳性 | 150×3=450 |
| 第4周 | 塌房信号窗口——对信心值最高的嫌疑人发起对质 | 2000（对质） |
| 第4周后半 | 对质命中！选择揭穿或放过，获得应援值返还 | 返还~3000+奖励 |
| 第5周 | 社区投票推C位上去，继续买入C位股份 | 1500 |
| 第6周 | 确保C位进入前11名，收集C位验证签名 | 500 |
| 第7周 | Phase 3终局战，确保C位存活 | 观察C位状态 |
| 第8周 | 全部应援值投入最终投票，C位投第1名 | 全部剩余 |

**总资源流**：起始5000 + 7周收入（~5800）= ~10800。对质2000 + 观察扫描~2000 + 股票/投票~4000 + 自省/应急~800 = ~8800。留有~2000余量。

**这条路的前提**：Phase 1脉冲触发准确、Phase 2对质命中、认知失调控制得当。不是每局都能走这条路——但这是"准备充分的玩家"应该追求的路径。

## 失败的常见原因

| 失败原因 | 占比预估 | 如何避免 |
|----------|----------|----------|
| 认知失调失控，脉冲失灵，无法锁定孽缘 | 30% | 不辩护+自省+利用Phase 3脉冲收敛 |
| 3次对质全部错杀（假阳性误导） | 25% | 不只靠脉冲，交叉验证行为线索+应激反应 |
| 从未对质（犹豫不决） | 15% | 第4周是最佳对质时机，别拖到赛季结束 |
| 主线胜利但C位被淘汰（前期没护盘） | 15% | Phase 1就给C位候选买少量股份 |
| 主线胜利但最终投票投错人 | 10% | 确信值满3点后再投，不要赌 |
| 放过孽缘后孽缘波及C位 | 5% | 放过时评估CP纠缠风险，有纠缠时选揭穿更安全 |

> **一句话总结**：别信任何人的表面，信你自己的脉冲+观察+证据板。先用3次对质机会命中孽缘（主线），再把你全部的信任投给你的C位（条件线）。别信，但最后要学会信对一个人。
