**外貌**：身高188cm，C纪元最高的练习生。银灰色短发修剪得一丝不苟，像一件展品。瞳色极浅的灰——在C纪元的冷光下几乎是透明的。穿着标准黑色制服，但裁剪比其他人更合身——不是为了好看，而是因为衣服不合身会影响走位精度。站姿永远笔直，像一把尺。

**反纪元特征**：C纪元的人冷面是因为"表情管理"，Hugo的冷面是因为"他真的不关心"。他的冷不是表演，是本能——他的注意力永远在舞台的灯光角度和地板摩擦系数上，对人的关注近乎为零。在所有人都在"管理表情"的C纪元，一个"根本不需要管理"的人反而是异类。

**背景故事**：C纪元排名第二的练习生，仅次于Leon。在原纪元就是"技术流"偶像的代表——走位精确到帧，灯光配合到毫秒。他的舞台表演在技术层面无可挑剔，但粉丝增长始终停滞——因为他对粉丝毫无感觉。

他的粉丝回馈值只有25。签售会上他会精确完成所有流程——握手、微笑、说谢谢——但每个动作的持续时间完全相同，像是流水线。他不讨厌粉丝，粉丝对他来说只是"舞台的一部分环境"，和灯光、音响没有本质区别。他不会记住任何粉丝的名字，就像他不会记住某盏灯的型号。

他的舞台热忱值高达88——比Leon还高。他对舞台有近乎偏执的热爱：他会花三小时调整一个走位的角度差，会为了一个灯光切换的时机和工作人员争论。舞台对他来说是纯粹的艺术品，而粉丝是欣赏艺术品的人——他们应该安静地欣赏，而不是上来打扰创作者。

**三轴信号呈现**：
- 舞台热忱信号：练习时全神贯注，瞳孔在灯光下自然放大（真），走位精度与投入度极高匹配（真），但完美中缺少"人"的温度
- 粉丝回馈信号：签售动作完全标准化（假），无镜头时对粉丝的存在毫无感知（极假），但不是厌恶而是真正的"无感"
- CP羁绊信号：对Mark有一种不被自己承认的关注——会在Mark练习时默默调整练习室的灯光角度

**玩家判断难点**：Hugo的舞台热忱极高，容易让玩家误判他为"Leon2号"。但他的粉丝回馈极低（25），是塌房信号高危角色。关键区别：Leon的冷面下藏着对人的关注（会在谢幕时扫视观众），Hugo的冷面下是真的没有人——他只看见舞台。玩家需要在"观察他对粉丝的态度"上下功夫，而不是被他的舞台表现迷惑。

**CP关系**：对Mark有55的羁绊——可能是欣赏Mark的勤奋（Hugo能分辨"努力"和"天赋"，他尊重努力的人），但他不会表达这种欣赏。

**三轴信号呈现**：
- 舞台热忱信号：表演中规中矩（真），走位偶尔出错（真），但不会因此沮丧——舞台对他来说不是最重要的

- CP羁绊信号：与Luke形成真实互动（真），会在Luke帮忙时自然地靠近对方

真相是：Ash是T纪元的第5名本命候选——三轴真心值全部在60以上。他确实是一个"好人"——真心爱舞台（82），真心爱粉丝（78），能建立真实羁绊（75）。他出现在T纪元的原因是：T纪元也会召唤出正常的人。不是每个T纪元的人都是极端的——T纪元的"极端"是纪元特征，不是每个人的特征。Ash是T纪元"正常的那一面"。

但他的"正常"在T纪元的极端环境中是一种危险——他会被其他T纪元角色拉扯。Kai的断裂会影响他，Milo的赎罪会吸引他。他对Milo有75的羁绊——不是因为"同病相怜"（他们没有相似的病），而是因为他看到了Milo在极端中保持善良的可能性，这给了他自己保持善良的勇气。

**三轴信号呈现**：
- 舞台热忱信号：表演有真实的温度（真），走位有"呼吸感"但比J纪元更有力量——是"稳定的火"而非"燃烧的火"
- 粉丝回馈信号：签售时目光真实（真），会记住粉丝的细节（真），无镜头时依然温和（真）
- CP羁绊信号：对Milo有深层关注（真），会与Milo的动作自然同步，但不像Bo那种依赖——是平等的共鸣

**玩家判断难点**：Ash是全游戏最复杂的判断之一——不是因为他的真心值难判断（他的信号都很真实），而是因为他的"环境"让玩家不敢相信。在T纪元——最危险的纪元、赎罪者比例最高的纪元——一个"完全正常的好人"看起来比Kai更可疑。玩家的半记忆脉冲会强烈闪烁（strong），不是因为Ash像上一世塌房偶像，而是因为T纪元的"危险气息"会触发玩家的创伤记忆。这是一个"假阳性"——脉冲说"危险"，真相是"安全"。

与Milo的"假阳性"不同：Milo是赎罪者（有前科但真心值高），Ash是新人（无前科且真心值高）。Milo的假阳性更难克服（因为赎罪者身份提供了"合理"的怀疑基础），Ash的假阳性更"纯粹"（没有任何合理怀疑的理由，纯粹是T纪元环境带来的恐惧）。

如果玩家能同时穿透Milo和Ash的假阳性，将两个T纪元本命候选送出道——这是游戏最难达成也是最 rewarding 的结局。

**CP关系**：对Milo（char_t02）有75的单向关注。两个T纪元"好人"之间的共鸣——一个赎罪者（Milo）和一个新人（Ash），他们的羁绊不是因为"同病相怜"而是因为"同路同行"。如果玩家在Phase 2/3将他们放在同一队伍，会触发T纪元最强羁绊加成。

### 30. Blaze

| 字段 | 值 |
|------|-----|
| ID | char_t04 |
| 纪元 | T |
| 赎罪者 | 否 |
| 本命候选 | 否 |
| 初始等级 | E |
| 舞台热忱 | 25 |
| 粉丝回馈 | 72 |
| CP羁绊 | 55 |
| 基础股价 | 25.3 |
| 脉冲强度 | strong |
| CP目标 | 无活跃CP |

**外貌**：身高185cm，高大但松垮——像一棵长歪了的树。火焰红色中长发，乱糟糟地炸开，T纪元最"乱"的发型——不是T纪元的"极端造型"，是真的不打理。瞳色是罕见的浅绿色——在T纪元的极端光影下像两簇鬼火。穿着T纪元风格但搭配混乱：黑色背心配破洞牛仔裤配军靴加一条不知道为什么系在腰上的红围巾——看起来像是把T纪元的衣橱炸了然后随便穿了几件。

**反纪元特征**：T纪元的人在舞台上都极具爆发力——Kai的燃烧、Milo的拼命、Ash的稳定之火。Blaze在舞台上完全不行——他会忘走位、会跟不上节奏、会在灯光切换时愣住。在T纪元"舞台就是战场"的群体中，一个"上不了战场"的人是最大的异类。但下了舞台，他是T纪元——不，可能是全30人中对粉丝最真心的人。

**背景故事**：T纪元垫底练习生。他的舞台能力是全30人中最差的——25的舞台热忱意味着他对舞台表演几乎没有任何天赋和热情。每次上台他都会出错，每次评价他都是最低分。按正常逻辑他应该在Phase 1就被淘汰。

但Blaze有一个T纪元其他人都没有的特质：他对粉丝有近乎纯粹的真心。72的粉丝回馈值——在T纪元4人中最高，比Kai（12）和Milo（80，但Milo是赎罪者有惩罚）都更显眼。他会在自己表演失误后跑到粉丝区道歉，会在签售时为每个粉丝画一幅简笔画（画得不好但是真的认真画），会在深夜回复每一条粉丝私信。

他不是不会"表演"——他是真的不想表演。Blaze对舞台的抗拒不是懒惰或叛逆，而是一种更深层的不理解：他不明白为什么要在舞台上"演"给陌生人看，而不是在台下"和"粉丝在一起。他可能走错了纪元——他应该去K纪元，那里他的粉丝回馈能力会被重视。但命运把他扔进了T纪元——最看重视觉冲击力和舞台表现的纪元。

**三轴信号呈现**：
- 舞台热忱信号：表演经常失误（真），走位跟不上（真），灯光切换时会愣住——不是紧张而是"忘了自己在哪"
- 粉丝回馈信号：签售时为每个粉丝画简笔画（真），表演失误后主动道歉（真），无镜头时依然认真回复粉丝（真）
- CP羁绊信号：55中等——他对所有人都有基本的善意，但不会与特定人建立深层关系

**玩家判断难点**：Blaze是全游戏最矛盾的角色——他的舞台热忱极低（25<30，是塌房信号阈值），但他的粉丝回馈是真的高的。脉冲强度strong是因为"某一轴极低但其他轴不低"的模式与上一世塌房偶像有相似之处——但Blaze的"低"不是伪装的，他真的不会表演。

玩家的判断困境是：他的低舞台热忱会不会在Phase 2触发塌房信号？如果他因为"关键时刻属性暴跌"被判定为塌房，他72的粉丝回馈能否证明他的真心？这是游戏中最"不公平"的设计——一个真心爱粉丝但不会表演的人，可能在机制上被判死刑。

如果玩家选择投资Blaze，赌的是"塌房信号不会被误触发"——这需要玩家在Phase 1为他积累足够的正面信号来抵消舞台表现的负面。高风险，但如果成功，Blaze的72粉丝回馈会在Phase 3的最终投票中提供独特的加成。
